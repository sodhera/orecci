Alarms and speech

Check time, repeat days, enabled state and iOS permissions. AlarmKit requires iOS 26 and authorization. Standard notifications can be silenced by Focus, Silent Mode or notification settings. Keep a separate dependable alarm for important wake-ups.

Allow Microphone and Speech Recognition in iOS Settings and select a language supported on your device. Audio is not sent to remote recognition. If recognition fails, use Stop alarm; test sessions can be exited.

Country selection works without location permission. Apple's map imagery and geocoding may need connectivity.

Accounts and purchases

Use Forgot password on sign-in to request recovery. Check spam folders and request a fresh link if expired. Never send a password or code to support.

Restore purchases checks eligible access for the Apple Account that purchased. It does not restore deleted settings. Local preview and Test Store purchases are free.

Report a problem

Include the app version, iPhone model, iOS version and steps to reproduce. For a passage concern, include its displayed source and language. Redact personal details from screenshots. Do not send passwords, codes, card details or recordings. We do not promise a fixed support response time; legal rights-request deadlines still apply.
