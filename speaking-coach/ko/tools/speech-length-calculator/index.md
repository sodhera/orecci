# 발표 시간 계산기: 원고 단어 수를 분으로, 분을 단어 수로

원고의 단어 수를 넣으면 분당 110, 140, 170단어 속도로 각각 몇 분 걸리는지 나오고, 주어진 시간을 넣으면 몇 단어를 쓸 수 있는지 나와요. 보통 속도(분당 140단어) 기준으로 3분이면 약 420단어, 5분이면 약 700단어예요. 한국어는 띄어쓰기 단위로 세기 때문에, 내 원고 일부를 직접 읽어 재 본 속도로 계산하면 더 정확해요.

## 사용 방법

- **원고가 이미 있다면:** 위쪽 칸에 단어 수를 넣으세요. 느림, 보통, 빠름 세 가지 속도로 걸리는 시간이 분:초로 나와요.
- **시간만 정해져 있다면:** 아래쪽 칸에 분을 넣으세요. 그 시간 안에 들어갈 단어 수가 세 가지 속도로 나와요.

단어 수는 띄어쓰기 기준이에요. 워드프로세서의 단어 수 세기 기능에 나온 숫자를 그대로 넣으면 돼요. "오늘 발표는 세 가지로 나눠서 말씀드리겠습니다"는 5단어예요.

## 한국어 원고는 내 속도로 맞추세요

위 속도들은 영어에서 흔히 쓰는 기준에 가까워요. 한국어는 어절 하나에 조사와 어미가 붙어 있어서, 같은 내용을 말해도 세어지는 단어 수가 영어보다 적게 나오기 쉬워요. 표의 숫자를 그대로 쓰면 원고가 시간보다 길어질 수 있어요.

정확하게 맞추는 방법은 간단해요.

1. 원고에서 아무 부분이나 골라 실제 발표하듯 1분 동안 소리 내어 읽으세요.
2. [말하기 속도 측정기](/speaking-coach/ko/tools/pace-checker/)로 분당 단어 수를 재세요. 예를 들어 95가 나왔다고 해 볼게요.
3. 주어진 시간에 그 숫자를 곱하세요. 3분이면 95 × 3 = 285단어가 내 원고의 목표 길이예요.
4. 원고 전체를 한 번 통으로 읽으며 시간을 재서 확인하세요.

## 자리별로 이렇게 준비해 보세요

| 자리 | 준비할 시간 | 원고에서 지킬 것 |
| --- | --- | --- |
| 1분 자기소개 | 50~60초 | 경험 한두 개만, 학창 시절은 짧게 |
| 결혼식 축사(친구) | 2~3분 | 일화 하나, 두 사람에 대한 덕담으로 마무리 |
| 송별회 인사 | 1~2분 | 감사할 사람과 기억 하나 |
| 퇴임사 | 3~5분 | 감사, 기억에 남는 순간, 남는 분들께 한마디 |
| 사내 발표 | 10~15분 | 슬라이드 한 장에 1분 안팎 |

이 시간은 정해진 규칙이 아니라 준비할 때 잡기 좋은 기준이에요. 사회자나 주최 측이 시간을 정해 주면 그 시간을 따르세요. [결혼식 축사](/speaking-coach/ko/speeches/wedding-toast/)나 [퇴임사](/speaking-coach/ko/speeches/retirement-speech/) 가이드에 구성과 예시 문장이 있어요.

## 원고가 너무 길 때 줄이는 순서

1. **배경 설명을 줄이세요.** 청중이 이미 아는 이야기부터 빼세요.
2. **일화를 하나만 남기세요.** 두 개라면 더 생생한 쪽만.
3. **"그리고", "또한"으로 이어진 문장을 끊으세요.** 짧은 문장이 말하기 쉽고 시간도 덜 들어요.
4. **결론은 남기세요.** 줄일 때도 마지막 문장은 그대로 두세요.

## 자주 묻는 질문

### 5분 발표는 원고가 몇 단어인가요?

보통 속도(분당 140단어)로 약 700단어예요. 한국어로 천천히 말하는 편이라면 더 적게 잡고, 직접 1분을 읽어 재 본 속도로 다시 계산하세요.

### 글자 수로 원고를 쓰는데 어떻게 하나요?

이 계산기는 단어 수로 계산해요. 원고의 단어 수 세기 결과를 넣거나, 1분 동안 읽은 분량을 글자 수로 세어 내 기준을 따로 만드세요.

### 시간이 남는 것과 넘치는 것 중 뭐가 낫나요?

조금 남는 쪽이 나아요. 실전에서는 긴장하거나 웃음이 나오거나 박수가 나와서 연습보다 길어지는 일이 많아요.

### 슬라이드는 몇 장이 적당한가요?

정답은 없지만 한 장에 1분 안팎으로 잡으면 계획하기 쉬워요. 10분 발표라면 본문 슬라이드 8~10장 정도로 시작해 보세요.
